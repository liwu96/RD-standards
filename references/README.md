# 参考材料与分发边界

本目录用于保存可公开再分发的来源索引、团队摘要和许可文件。规范正文中的来源映射见 [`../ATTRIBUTION.md`](../ATTRIBUTION.md)。

为了避免误分发受版权或内部访问限制的全文，第三方手册、图书和企业内部材料默认不放入仓库。需要引用时提交公开 URL、章节定位、短摘要或获得许可的摘录，并在 `ATTRIBUTION.md` 记录来源与许可。不要把密码、令牌、客户数据、内部工单或未授权的 PDF/网页抓取内容放入本目录。

如果某份材料确实允许再分发，请在其文件头写明来源、版本、许可和获取日期，并在此 README 或 `ATTRIBUTION.md` 增加索引。大型本地副本可放在未跟踪的 `references/local/`，该目录仅用于个人检索，不参与 TeamAI 同步。
