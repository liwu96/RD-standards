# 安全基线规范（通用）

> 适用范围：团队所有后端服务。语言专项安全条款见 `rules/java/java-backend-standard.md` §11（安全规约）、`rules/python/python-backend-standard.md` §28；数据库安全见 `rules/database/mysql-standard.md` §9；三方安全见 `rules/third-party/third-party-usage.md` §2。本文件是横向汇总的基线清单。

## 1. 提交前必查清单

每次涉及以下内容的改动，提交前逐项自查：

- [ ] 无硬编码密钥（API key、密码、token、连接串）
- [ ] 所有外部输入（HTTP、MQ、三方返回、文件）经过校验后才进业务
- [ ] SQL 全部参数化绑定，无字符串拼接
- [ ] 输出到页面的用户数据有转义/过滤（防 XSS）
- [ ] 表单/AJAX 有 CSRF 防护
- [ ] 鉴权与权限校验完整（含水平越权：不能操作他人资源）
- [ ] 敏感数据展示脱敏（手机号、身份证、卡号）
- [ ] 错误信息不泄露内部细节（堆栈、SQL、表名、内网地址）
- [ ] 上传文件校验类型/大小，路径不可控（防路径穿越）
- [ ] 短信/邮件/支付等资源有防重放（频控、验证码、数量限制）

## 2. 密钥管理

- 【强制】密钥只放配置中心或环境变量；启动时校验必需密钥存在
- 【强制】疑似泄露立即轮换（删除提交不消除泄露），并通知安全负责人排查访问日志
- 【推荐】密钥支持定期轮换；仓库开启密钥扫描

## 3. 依赖与供应链

- 【强制】三方库引入前过 License 与 CVE 检查（见 `rules/third-party/third-party-usage.md` §1）
- 【强制】CI 运行依赖漏洞扫描（OWASP dependency-check / pip-audit），高危未处理不得发布
- 【推荐】锁文件固化依赖版本，禁止浮动版本号

## 4. 接口安全

- 【强制】对外接口默认鉴权，公开接口显式声明并评估滥用风险
- 【强制】接口限流（网关或应用层），防刷防遍历（连续 404/遍历 ID 告警）
- 【强制】管理类接口（后台、运维）独立鉴权域 + IP 白名单
- 【推荐】返回体最小化：列表接口不返回密钥类字段（哪怕是空的）

## 5. 数据安全

- 【强制】密码存储用慢哈希（bcrypt/argon2），禁止 MD5/明文
- 【强制】日志脱敏：token、密码、手机号、卡号不整段输出
- 【推荐】个人敏感字段（身份证、地址）数据库层加密或独立表隔离
- 【推荐】数据导出类功能审计留痕（谁、何时、导出了什么）

## 6. 安全事件响应

发现安全问题（自测、评审、扫描、外部报告）时：

1. **停止**：暂停相关改动与发布
2. **评估**：影响面（数据、资金、用户量）与攻击路径
3. **止血**：修复 CRITICAL 后再继续；必要时下线接口/关闭功能开关
4. **轮换**：泄露的密钥全部轮换
5. **排查**：全库排查同类问题（同一模式的其他出现点）
6. **复盘**：按事故等级走复盘流程（见 `rules/common/development-workflow.md` §5），产出规范/检查项的增补
